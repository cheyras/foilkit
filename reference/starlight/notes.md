# Starlight

Video chapter: **0:00 - 0:45** of [All 39 Pokemon Card Holo Patterns Explained](https://youtu.be/wQ2TvnHVdys) by **Sleeve No Card Behind**.
Frames: 8 keyframes spanning the tilt demo at 23.0s-30.5s; clip: 24.0s-27.5s (360p, silent).

## Cards / material shown

- Blastoise (Base Set)
- Machamp (Base Set, overlay transition)
- Flareon (Jungle)
- Uncut star-foil sheet with yellow card borders printed on ('left the yellow borders on just for fun')
- Japanese Base Set Charizard (comparison - JP used Cosmos)
- Base Set / Jungle booster packs

## Usage claim (per the video)

Base Set, Jungle, Fossil - international (non-Japanese) printings only; Japanese equivalents used Cosmos.

## Notes

One of the only true holograms in the TCG: front star layer moves side-to-side against the back layer (3D parallax). 'Galaxy' is an old name for this star foil (see cosmos notes).
