## Usage claim (per the video)

First on English cards in Base Set 2; WOTC experimented with it earlier (e.g. Fossil cosmos copies given to WOTC employees, non-mainline promos). Japanese Base-era holos used it from the start. Later the dominant promo pattern (see cosmos-ii/iii).

## Notes

Pixelated orbs, sometimes swirls; swirl placement/count carries a collector premium. NAMING: 'Galaxy' is an old name for the STAR foil (starlight), commonly MISUSED for cosmos; the creator (and this repo) phases 'galaxy' out.
