# Generated masks: what is in them and where each shape came from

The rows under `sets/` point at machine-generated foil masks (bytes in the `foilkit-masks` bucket). Each mask is
foil STRENGTH over the card face. Every value in one is produced by our own code from rules, from our own vector
modules, or from the shapes listed below. No game asset, plate, texture or shader went into any mask.

## Shapes and their sources

| Shape | Source | Decision |
|---|---|---|
| Frame cuts: face, window, name bar, panels, discs, bevels and other regular-frame shapes | Hand-drawn modular vectors by @cheyras (VectorCraft, 2026-10-18) | Original work |
| Card text cut-outs (names, attack text, labels) | Typeset from font files with @cheyras's measured styles (tracking, kerning, skew, stroke) | Original layout |
| Trainer header labels (TRAINER, Item, Supporter, Stadium, Pokémon Tool) | Image-traced by @cheyras from upscaled card imagery, then hand-adjusted; not exact copies | Accepted by @cheyras, 2026-10-18: "They are traced but they're not even close to exact." |
| Energy-type symbols inside the SV reverse-holo patterns (mosaic and medallion) | Traced from public TCGdex card scans by sub-pixel averaging many small icons into one outline | Accepted by @cheyras, 2026-10-18: "Use the traces from tcgdex." Original drawings may replace them later. |
| Reverse-holo pattern layout (mosaic tiling, medallion placement, per-set gain) | Generated by our own code from measured statistics (period, gain, placement); no layout was copied | Original generation |
| Subject cut-outs (the Pokémon or character in holo and full-art masks) | Per-card output of open segmentation models (BiRefNet, isnet-anime, Depth Anything V2) run on the card scan | Machine output, no shape carried over |

The type symbols and Trainer labels are trademark-bearing marks. AGENTS.md F2 bars traced trademark glyphs from
the repository, so none of these shapes is committed as a glyph or tile. They exist only inside the generated
masks, as foil-strength coverage. The maintainer accepted that, and the decision is recorded here.

## Status

All rows are machine guesses (`ai`, unreviewed). They answer only where `data/foil-masks/` has no record and
never become exemplars. See DECISIONS.md, 2026-10-18.
